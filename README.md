# Vice City Actual Next Gen for GTA IV — Linux / FusionFix Overloader Port

A community port for people playing GTA IV on Linux who want to play Vice City Actual Next Gen without editing GTA IV’s original game files.

This project uses Kn4ckers’ [Vice City for GTA IV FusionFix port](https://github.com/knackers4/vce/releases/tag/vce) as its base. I ported and integrated content from the latest Actual Next Gen version and the **Vice City HD Lore-Friendly Car Pack**, while retaining the FusionFix Overloader setup. The port does not depend on Script.NET hooks, which are not Proton-friendly.

The Overloader approach keeps the modded content in GTA IV’s `update` folder rather than replacing the game’s original files. This can help avoid the Rockstar Games Launcher restoring edited files on startup, while allowing you to continue using the launcher and Social Club.

## Installation

1. Install GTA IV and FusionFix Overloader.
2. Copy the contents of this project into GTA IV’s `update` folder, keeping the included folder structure.
3. Launch the game.

You may need to increase the vehicle budget in FusionFix and set **Pedestrian Limits** and **Extended Limits** to `1`.
