DLSS-IV is a mod for Grand Theft Auto IV and Episodes from Liberty City.
Downloads, questions and bug reports: https://www.nexusmods.com/games/gta4/mods/1430

NVIDIA DLSS SDK
  dlssiv-helper.exe is compiled against the NVIDIA DLSS SDK headers and
  linked with its import library. Neither is in this repository:
  tools/fetch-ngx.ps1 fetches them from https://github.com/NVIDIA/DLSS, and
  they are under NVIDIA's licence (fetched with them as
  external/ngx/LICENSE-NVIDIA-DLSS-SDK.txt).
  This software contains source code provided by NVIDIA Corporation.

Intel XeSS SDK
  dlssiv-helper.exe is compiled against Intel's XeSS headers and loads
  Intel's libxess.dll at run time. Neither is in this repository:
  tools/fetch-xess.ps1 takes them from Intel's release at
  https://github.com/intel/xess, under the Intel Simplified Software License
  (fetched with them as external/xess/LICENSE-Intel-XeSS.txt).

GTAIV.EFLC.FusionShaders and GTAIV.EFLC.FusionFix
  source/hdr_xbox_gamma.h holds the 256 values of the Xbox 360 gamma curve
  published with GTAIV.EFLC.FusionShaders. The HDR path repeats the
  arithmetic of FusionFix's console gamma pass, and the dither pass makes the
  decision of the game's stipple filter and reads the mark FusionFix's
  shaders write; both were written again for this project from those rules,
  with its own names. Credited to their authors.
